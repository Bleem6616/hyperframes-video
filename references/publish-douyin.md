# 发布前置（抖音为主）

成片的最后一步不是"导出"，是"能过审、能进流量池"。下面每条都是实测或联网核查过的结论，不是通则。

## 一、先看三个硬指标

```bash
ffprobe -v error -show_entries format=duration,bit_rate -show_entries stream=codec_name,width,height,r_frame_rate -of default=noprint_wrappers=1 out.mp4
```

| 项 | 抖音信息流要求 | 说明 |
|---|---|---|
| 画幅 | **9:16（1080×1920）** | 16:9 横屏在信息流里上下黑边，实际显示面积只有屏幕约 1/3 |
| 码率 | **6–12 Mbps** | 低于 2 Mbps 时纯色渐变会压出色带（banding） |
| 音轨 | 有或无皆可 | 若在 App 内挂站内音乐，导出**无音轨**版本更干净 |

竖屏是**重新排版**（字号放大、图形改上下分布、核心内容放中间 60%），不是给横屏加黑边——伪竖屏（上下模糊填充）观感廉价，完播率通常更低。

## 二、合规标注（硬性）

- 发布时必须从 6 类标签中选一项才能发出：含有虚构演绎内容 / **含有AI生成内容** / 含有营销信息 / 内容为转载 / 内容为个人观点 / 无需标注。
- AI 生成画面 → **勾选「含有AI生成内容」**。平台对未主动标识的 AI 内容会自动补标并写入隐式标识（元数据），主动勾选不损失任何东西。
- 引文需逐字核对（王阳明 / 苏轼 / 曾国藩等原文属公有领域，无版权风险，但引错会被评论区抓）。
- 画面中不得出现其他平台水印。

## 三、AI 配音的边界

| 平台 | 规则性质 | 后果 |
|---|---|---|
| 抖音 | **强制标注义务**（AIGC 角标 + 隐式标识） | 不标属违规、可扣分；音频指纹能自动识别 AI 合成人声并补角标 |
| 快手 | 创作活力分明确**禁止** AI 配音 | 该项拿不到分（非封号级） |
| 小红书 | 未如实声明 → 单篇流量递减 50% | 影响单篇，声明可规避 |
| 视频号 / 公众号 | 经实质编辑加工，AI 辅助可申请原创 | 相对宽松 |

三条底线：发布时勾选 AIGC 开关 + 画面里打一行半透明"AI 配音"小字；不克隆他人声音（含明星、配音演员）；不商用侵权素材。

**形态风险（关键判断）**：平台真正打击的是"**素材是搬来的 + 声音是合成的 + 观点是模板套的**"这个组合。全 AI 画面 + 无真人 + AI 配音的片子形态上正落在该画像内，易被判流水线内容而限流。折中做法：开头真声口播一句、片中插一段实拍、结尾用自己的声音下结论——**哪怕只做到"开头真声 5 秒"，形态就从流水线变成"有人参与"**。

## 四、横屏还是竖屏：一个真实取舍

抖音「中视频计划」的分成要求是**横屏原创 + 时长 ≥1 分钟**（约 2–4 元/万播放，可同步西瓜/头条）。

- 竖屏：信息流曝光与完播率更好。
- 横屏：可吃中视频分成，但信息流表现差。
- **可以两吃**：主体做竖屏发抖音，另用横屏版投中视频计划。（该计划的存续与门槛需在创作者服务中心确认后再投。）

## 五、BGM

- **版权优先**：在抖音发布页的「音乐」里搜同名曲。搜得到 → 平台已授权，放心用；搜不到又只能用站外 mp3 → 音频指纹会识别，轻则限流/静音，重则下架。未授权的第三方 remix 版本风险更高。
- **站内"同款"要验拍**：同名曲可能是另一个 remix 版本，卡点会整体错位，**需要重新对拍**（见 `beat-sync.md` 第二节）。
- **人声冲突**：带 vocal 的 BGM 再叠中文旁白会打架 → BGM 压到 −18 ~ −22 dB 并避开人声段，或改用伴奏版。
- **峰值**：抓取来的音频常已顶满 0 dBFS，二次导出至少留 −1 dBTP，否则平台压缩会让副歌更糊。

## 六、话题选择：先判断匹配度

话题不是越多越好，**内容与话题不符会被限流**。

- `#VibeCoding大赏`（抖音科技发起，累计超 12.5 亿播放，配套 `#ai新星计划`）要的是"我用 Vibe Coding 做出了什么作品"，通行形态是**口播解说 + 录屏演示**。
- 一条"讲某个道理的动画片"硬带该话题 → 错配。正确切法是把**"这条视频本身怎么做出来的"当作品**（剧本 → 生成工程 → lint → 渲染的过程展示 + 踩坑），这才是选手想看的"作品"。
- 若走该话题：标题以「VibeCoding大赏」开头，话题 `#vibecoding大赏 #ai新星计划`，@抖音科技。
- 通用科普内容：`#读书 #知识科普 #AI创作` 等与内容直接相关的话题即可。

## 七、交付形态（默认只给无音轨版）

**用户默认约定：无特别声明时只交付无音轨版**（用户在抖音 App 内挂站内音乐库同款，带音轨版是多余产物）。

| 文件 | 用途 | 生成方式 |
|---|---|---|
| `xxx_无音轨.mp4` | **默认交付**；平台内挂站内音乐 | `"$HF_FFMPEG" -v error -y -i in.mp4 -c copy -an out.mp4`（流复制，不重编码） |
| `xxx.mp4`（带音轨） | 仅在用户明确要时交付；本地核对卡点、其他平台发布 | 正常渲染 |

工程内**照常挂 BGM**——阶段 1 的 BPM / 拍网格、卡点切点全都依赖它，只是渲染后去掉音轨再交付。

## 八、发布前 checklist

- [ ] 画幅 / 分辨率 / 码率达标
- [ ] 首帧不是黑场或纯渐变（信息流展示第一帧）
- [ ] 前 3 秒直接上有效画面
- [ ] 竖屏版核心大字在中间 60% 安全区内
- [ ] 勾选 AI 生成标注
- [ ] 引文逐字核对
- [ ] 站内音乐库搜到同款；搜到后验拍
- [ ] 封面：竖版自绘或选帧，封面文字别过多
- [ ] 话题与内容匹配（不硬蹭）
